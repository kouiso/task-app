## (c) 理解チェック3問（起案）

**Q1（このコードは何をしとるか）** `globals.css` の `--color-primary: hsl(var(--primary));` の行は何をしているか。
**A**: Tailwind に「`bg-primary` と書かれたら変数 `--primary` の色を使ってよい」と教える対応表の1行。色の実際の値はここでは決まらず、`:root`（明るいテーマ）と `.dark`（暗いテーマ）で別々に決まる。（`:555`, `:648`）

**Q2（こう変えたらどうなるか）** `:root` の `--radius: 10px;` を `20px` に変えると、画面はどうなるか。
**A**: 画面中の角丸がまとめて大きくなる。`--radius-sm` / `-md` / `-lg` / `-xl` はすべて `calc()` でこの `--radius` から計算して作ってあるため。（`:597-600`, `:710`）

**Q3（なぜこの書き方か）** 「今日のゴールを見る」は `<a href="#today-goals">`、「ダッシュボードへ入る」は `<Link href="/dashboard">` と書き分けているのはなぜか。
**A**: 前者は同じページの中に付けた `id="today-goals"` という目印へスクロールする移動で、後者は別のページへの移動。Next.js の `Link` はページ全体を読み込み直さずに画面を切り替えるので、アプリ内のページ移動には `Link` を使う。（`:872`, `:936`）

## (c) 理解チェック3問（起案）

**Q1** `isAuthenticated` の中で `prisma.user.findUnique` を引き直し、`role: currentUser.role` で上書きしているのは何をしているか。
**A**: JWT に入っている `role` はログインした瞬間の値で固定されているので、リクエストのたびにデータベースの最新の権限を取り直して差し替えている。これが無いと、管理者権限を外した相手がトークンの期限（7日）が切れるまで管理者として動ける。（`:490-493`, `:538-540`）

**Q2** `createSession` の `Math.floor(Date.now() / 1000)` から `/ 1000` を消すと何が起きるか。

**Q3** `login` で「そのメールアドレスは存在しない」と「パスワードが違う」を、同じ文言（`メールアドレスまたはパスワードが正しくありません`）で返しているのはなぜか。
**A**: 区別して返すと、攻撃者が総当たりで「このサービスに登録済みのメールアドレスの一覧」を作れてしまうから。同じ理由で、`isActive` の判定もパスワード照合より**後ろ**に置いている。（`:774`, `:801-805`, `:871`）

## (c) 理解チェック3問（起案）

**Q1** `AppLayout` の `if (!hasMounted || isLoading) { ... }` と `if (!session?.user) { return null; }` の2つは何をしているか。
