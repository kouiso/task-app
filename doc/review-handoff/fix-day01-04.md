## 3. 目次との食い違いは「本文へ足す」で寄せた

`00_カリキュラム目次.md:84-89` は Day 02 の内容として次の3つを約束していた。

- 変数の基本（const と let の違い）を体験
- TypeScript の型（string, number, boolean）を学ぶ
- 型エラーを体験・修正する

Day 02 本文を全文検索したところ、`let` は0回、`boolean` は0回、`number` は型注釈として1回出るだけで解説なし、型エラーの演習は存在しなかった。

**判断: 目次を削らず、本文に足した。** 理由は3つある。

1. 目次は購入前に読まれる。約束を削ると、商品の内容そのものが減る。
2. 足す内容が Day 02 のコードと地続きだった。`const currentHour = new Date().getHours();` は `number`、`hour < 12` の結果は `boolean`、`getGreetingByHour` の戻り値は `string` で、3つの型が同じ関数の中にすでに並んでいる。新しい題材を持ち込まずに書けた。
3. 型エラーは「読んで理解する」より「出して見る」ほうが速い。手元で再現できる形にした。

**足したもの**: Day 02 Step 2 の末尾に `#### 型と変数を、その場で確かめる`（約40行）。

- `const currentHour` に代入し直して `Cannot assign to 'currentHour' because it is a constant.` を出す → `let` に変えると消える → それでも `const` を既定にする理由
- `number` / `string` / `boolean` の3つが `getGreetingByHour` の中で順に出ていることの確認
- `getGreetingByHour('9')` に書き換えて `Argument of type 'string' is not assignable to parameter of type 'number'.` を出す → 元に戻す
- 確認ポイント4項目（一時的に書き換えた2か所を戻したことを含む）

あわせて `## 今日のゴール` のチェックリストに1項目、`## 今日学んだ用語` に `const` / `let` / `string`・`number`・`boolean` の行を足した。目次側は1行だけ直した（存在しない「ウェルカムバナー」→「自分だけのメッセージカード」）。
