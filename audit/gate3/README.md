## やり方

1. 初心者役が、教材の本文だけを読んで1日ぶんを通す。`src/` を読むことは禁じた。
   詰まった箇所を行番号と逐語引用つきで挙げる。
2. 別の判定者が、挙がった1件ずつを「その指摘は成立しない」を既定の立場として反証する。
   前の日で埋まっていないか、同じファイルの別の場所で埋まっていないか、
   配布済みの足場で埋まっていないかを現物の行で確かめる。
3. 生き延びた件も、反証で消えた件も、両方を `dayNN.md` へ全件残す。
   消えた件には、反証側が示した根拠をそのまま載せている。
