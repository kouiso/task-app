# Gate3 初心者シミュレーション — 30日ぶんの実施記録 (2026-07-28)

教材の品質基準のうち、#8 と #9 は「初心者が本文だけで実際に通せるか」を問う項目である。
これまでこの2項目には根拠となる判定ログが1件も無かった。この記録がその根拠にあたる。

## やり方

1. 初心者役が、教材の本文だけを読んで1日ぶんを通す。`src/` を読むことは禁じた。
   詰まった箇所を行番号と逐語引用つきで挙げる。
2. 別の判定者が、挙がった1件ずつを「その指摘は成立しない」を既定の立場として反証する。
   前の日で埋まっていないか、同じファイルの別の場所で埋まっていないか、
   配布済みの足場で埋まっていないかを現物の行で確かめる。
3. 反証を生き延びた件だけを `dayNN.md` へ書く。

## 結果

| 区分 | 件数 |
|---|---|
| 初心者役が挙げた詰まり | 109 件 |
| 反証を生き延びた詰まり | 33 件 |
| 生き延びた件が 0 だった日 | 16 日 |

日ごとの内訳は各 `dayNN.md` の先頭にある。

生き延びた件が多い日は Day 11（7件）、Day 12（5件）、Day 18（4件）、Day 14（3件）。
この4日で全体の 19 件、生き延びた件の半分以上を占める。

## この記録で言えないこと

1. **判定者は AI である。** 実際の初心者が同じ所で詰まるかは測っていない。
2. **Day 02 の 0 件は、確かめ切った 0 ではない。** 3件のうち1件は反証する側の実行が
   途中で切れ、判定が返らないまま「生き延びなかった」に数えられている。詳細は `day02.md`。
3. **生き延びた 33 件は、まだ直していない。** この記録は洗い出しであって修正ではない。
